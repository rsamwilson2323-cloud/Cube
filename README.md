# 🧊 Cube Animation

A visually engaging web project that showcases a dynamic cube using modern web technologies. This project focuses on smooth animations, 3D transformations, and clean UI design to deliver an interactive front-end experience.

---

## 🚀 Features

- 🧊 3D cube visualization  
- 🎨 Smooth animations and transitions  
- ⚡ Lightweight and fast  
- 📱 Responsive design  
- 💻 Clean and minimal UI  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript
